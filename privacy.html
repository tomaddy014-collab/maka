Privacy & Data Statement

Last updated: 12 June 2026

Māka is an AI-assisted marking tool for New Zealand teachers. This page explains exactly what data Māka handles, where it is stored, and how it is protected — written for teachers, school leaders, and whānau.

What data Māka stores

AboutDataWhy
StudentsName, year level, gender (optional, for report pronouns), marking results and feedback, uploaded work files (PDF/photo)Marking, progress tracking, report writing, the student's own learning page
TeachersEmail, display name, writing-style examples, Gemini API key, saved rubrics and sessionsAccount sign-in and tool features

Māka collects no analytics, uses no advertising or tracking technology, and never sells or shares data with anyone.

Where it is stored

All data is stored in a single Supabase project (managed PostgreSQL database and private file storage) administered by the Māka operator. Each teacher's data is isolated by database row-level security — teachers cannot see one another's students or results. Student work files live in a private storage bucket that is not publicly accessible; files are only ever served through expiring signed links.

AI marking and model training

Student work is not used to train AI models. Marking is performed by Google's Gemini API on the paid tier, whose terms of service state that prompts and responses are not used to train or improve Google's models. Each piece of work is processed once to produce marks and feedback, then discarded by Google (apart from short-term abuse-monitoring retention).

Teachers using their own Gemini key are instructed in the tool to use a key on a billing-enabled (paid tier) project for exactly this reason. Free-tier keys fall under different Google terms that permit training use, and are not recommended for student work.

Who can access what

  • Teachers see only their own class, results, and files.
  • Students access only their own results, via a private code their teacher gives them. No student accounts or passwords exist.
  • The operator administers the database and storage, and does not access teachers' or students' content except where required to maintain the service.
  • Third parties: two processors only — Supabase (hosting/storage) and Google Gemini (transient marking). Nobody else.

Retention and deletion

Data is kept until the teacher deletes it. Teachers can delete individual students, marking sessions, or their entire account (Settings → "Delete my account and all data") at any time. Deleting the account removes the associated records.
